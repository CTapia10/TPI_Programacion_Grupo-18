## 📖 Descripción del Proyecto

**Food Store** es un sistema de gestión de pedidos de comida desarrollado como una aplicación de consola en Java. El objetivo principal del sistema es permitir la administración integral de un negocio gastronómico mediante operaciones CRUD (Alta, Baja, Modificación y Consulta). 

El sistema gestiona:
* 📁 **Categorías**
* 🍔 **Productos**
* 👥 **Usuarios** (Roles Admin/Usuario)
* 🛒 **Pedidos** y Detalles de Pedido

El desarrollo aplica los conceptos fundamentales de la Programación Orientada a Objetos (POO) como encapsulamiento, herencia, polimorfismo y abstracción, utilizando colecciones en memoria, manejo de excepciones y enumeraciones.

## 🚀 Cómo ejecutar el proyecto

El proyecto es una aplicación de consola estándar de Java. No requiere de bases de datos externas ya que persiste los datos en memoria mediante colecciones durante la ejecución.

### Requisitos previos
* Tener instalado **Java Development Kit (JDK)** (versión 8 o superior).
* Un IDE compatible (NetBeans, IntelliJ IDEA, Eclipse) o terminal de comandos.

### Pasos para la ejecución

**Opción 1: Usando un IDE (Recomendado)**
1. Clona este repositorio en tu máquina local:
   ```bash
   git clone [https://github.com/CTapia10/TPI_Programacion_Grupo-18.git](https://github.com/CTapia10/TPI_Programacion_Grupo-18.git)
   ```
2. Abre tu IDE favorito y selecciona la opción de "Abrir Proyecto" o "Importar Proyecto".
3. Navega hasta la carpeta clonada y selecciona el proyecto.
4. Busca la clase principal ubicada en `src/integrado/prog2/Main/Main.java`.
5. Ejecuta la clase `Main.java` (Run File / Run Project). El menú interactivo aparecerá en la consola del IDE.

**Opción 2: Usando la Terminal de comandos**
1. Clona el repositorio y navega al directorio de código fuente:
   ```bash
   git clone [https://github.com/CTapia10/TPI_Programacion_Grupo-18.git](https://github.com/CTapia10/TPI_Programacion_Grupo-18.git)
   cd TPI_Programacion_Grupo-18/src
   ```
2. Compila los archivos Java:
   ```bash
   javac integrado/prog2/Main/Main.java
   ```
3. Ejecuta la aplicación:
   ```bash
   java integrado.prog2.Main.Main
   ```
